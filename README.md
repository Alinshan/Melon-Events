**Melon Events** is a professional, local-first rental management and billing solution designed specifically for catering and event businesses. Streamline your inventory tracking, manage staff salaries, and generate premium invoices with ease.

---

## ✨ Key Features

### 📊 Comprehensive Dashboard
- **Real-time Analytics**: Track total earnings, business expenses, and net profit at a glance.
- **Inventory Status**: Monitor active rentals and items pending cleaning.
- **Profit Tracking**: Automated calculation of net margins accounting for travel, salaries, and damages.

### 🧾 Smart Billing & Invoicing
- **Premium PDF Invoices**: Generate professional, branded invoices with custom vector logos and itemized totals.
- **Rental Management**: Track plate and glass counts, custom pricing per rental, and discounts.
- **Return Processing**: Manage returned items with integrated damage charge calculations.

### 🧹 Staff & Operations
- **Salary Automation**: Automatically calculate cleaning staff wages based on item counts (plates/glasses).
- **Expense Logging**: Track travel costs and other business overheads to maintain financial health.
- **Inventory Control**: Manage total stock levels and track "items out" in real-time.

### 📂 Data Management
- **Local Persistence**: Fast, offline-capable storage via Electron.
- **Excel Export**: Export rental, salary, and expense records to `.xlsx` for external accounting.
- **Branded Design**: High-performance UI with smooth animations and a premium dark-mode aesthetic.

## 🚀 Getting Started

### Prerequisites
- [Node.js](https://nodejs.org/) (Latest LTS recommended)
- [npm](https://www.npmjs.com/)

### Installation
1. **Clone the repository:**
   ```bash
   git clone https://github.com/Alinshan/Melon-Events.git
   cd Melon-Events
   ```

2. **Install dependencies:**
   ```bash
   npm install
   ```

3. **Run in development mode:**
   ```bash
   npm run dev
   ```

4. **Build the production application:**
   ```bash
   npm run build
   ```
   *The packaged app will be available in the `/release` directory.*
